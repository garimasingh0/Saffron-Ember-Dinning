# BankSphere AI
> **Smart Banking. Smarter Decisions.**

A next-generation, professional, modern, and responsive banking and autonomous financial management web platform. Built with an institutional aesthetic inspired by leading global fintechs (Stripe, Mercury, Revolut, Wealthfront), BankSphere AI combines high-yield treasury management, conversational AI copilot advisory, predictive cashflow forecasting, instant cross-border settlement rails, and quantum-safe threat defense.

---

## 🌟 Key Features

### 1. Modern & Responsive Visual Experience
- **Fintech Luxury Theme**: Deep obsidian / cosmic navy palette (`#080C15`) with radiant electric cyan (`#00F2FE`), neo indigo (`#6366F1`), and growth emerald (`#10B981`) accents.
- **Glassmorphic UI**: Backdrop blur cards, micro-interactions, subtle glowing borders, and ambient background lighting.
- **Theme Switcher**: Instant toggle between **Midnight Dark** and **Clean Slate Light** mode with local persistence.
- **Multi-Currency Converter**: Switch between **USD ($)**, **EUR (€)**, **GBP (£)**, **JPY (¥)**, and **CAD (CA$)** with real-time conversion across all portal balances and calculators.
- **Fully Responsive**: Mobile touch navigation drawer, adaptive grids, and optimized mobile-first layout.

### 2. Holographic Card Visualizer
- **Interactive 3D Holographic Card**: Shimmering lighting animation, EMV microchip, contactless wave indicator, live embossed typography, and status indicators.
- **Floating AI Insight Card**: Real-time neural notification displaying automatic cash sweeps, fraud scores, and yield boosts.

### 3. Interactive Precision Calculators
- **AI Compound Wealth Simulator**:
  - Sliders for Initial Capital Deposit, Monthly Automated Contribution, Growth Horizon (Years), and APY Rate.
  - Dynamically calculates future value and compound interest earned with real-time feedback.
- **Instant AI Credit & Working Capital Simulator**:
  - Sliders for Credit Line Amount ($5,000 to $250,000) and Repayment Tenure (6 to 60 Months).
  - Displays instant monthly repayment, total financing cost, and algorithmic approval score (e.g. *99% Instant Pre-Approved*).

### 4. Live Interactive AI Banking Portal & Demo
- **Real-Time Financial Dashboard**:
  - Dynamic balance trackers: Net Portfolio ($148,920.85), Operating Checking, 5.4% High-Yield Vault, and Strategic Treasury Reserves.
- **Interactive Chart.js Visualizations**:
  - **Cash Flow Trends**: Silky-smooth area line chart comparing revenue inflow and operational expenses over time.
  - **Expense Breakdown**: Doughnut chart with automated neural category classification.
- **Card Security Controls**:
  - **Freeze / Unfreeze Card**: Real-time card locking with instant visual status badge updates.
  - **Reveal PIN / Mask PIN**: Securely inspect or hide card PIN.
  - **Copy Card Number**: One-click clipboard copy with animated toast notification.
  - **Monthly Spend Gauge**: Progress bar tracking credit limit utilization.
- **Interactive Smart Transfers & Wires**:
  - Modal with form validation to send funds via Sphere AI-Rail (instant $0 fee), FedNow wire, or SWIFT.
  - Automatically checks checking account balance, deducts funds, updates net worth, and prepends a new transaction to the live ledger!
- **Dynamic Transaction Ledger**:
  - Category icons, timestamps, AI verification badges, and filter tabs (*All*, *Inflows*, *Outflows*).

### 5. SphereAI Conversational Assistant Widget
- **Floating Chat Copilot**: Accessible from the bottom right on any screen.
- **Conversational Responses**:
  - Answers questions about account balances, 5.4% APY mechanics, and credit scores.
  - Supports quick action commands like *"Freeze my card"* or *"Analyze my spending"*.
  - Includes interactive prompt chips for instant answers.

### 6. Institutional Security & Compliance
- **$5,000,000 FDIC Insurance** via multi-bank sweep programs.
- **SOC2 Type II & ISO 27001** certified infrastructure.
- **Quantum-Safe 256-Bit AES** lattice encryption.
- **Biometric Zero-Knowledge** FIDO2 hardware verification.

## 🚀 Quick Start Guide

### Option 1: Direct Browser Launch
Simply double-click `index.html` or open it directly in any modern browser (Chrome, Edge, Firefox, Safari). Zero installation or build step required!

### Option 2: Local HTTP Server (Node.js / Electron)
If you have Node.js or the system runner:
```bash
# Using the built-in system node runner:
agy-node.cmd server.js

# Or standard Node.js:
node server.js
```
Then navigate to: **`http://localhost:3000`**
